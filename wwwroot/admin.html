4. Discord channels (webhooks)

Paste one webhook URL per channel you want to send to. No bot needed — right-click a channel in Discord → Edit Channel → Integrations → Webhooks → New Webhook → Copy URL.

5. Emoji for roles & tags

Custom server emoji: in Discord type \:youremoji: in any channel and send it — it turns into the raw code (like <:tank:123456789012345678>). Paste that here. Leave a field empty to use the default emoji. Bulwark markers are fixed (♜↑ top, ♜ center, ♜↓ bottom) and aren't customizable here.
