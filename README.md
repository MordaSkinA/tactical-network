# GvG Tactical Network — Phase 0 POC (Variant B)

Минимальный срез архитектуры для проверки гипотезы перед полноценной разработкой.
Без БД (события только в памяти процесса), без auth, без ролей — захардкоженные squad-ID.

## Что это

- `Server/` — ASP.NET Core 8 приложение с одним SignalR hub (`/battleHub`), broadcast всем подключённым.
- `Server/wwwroot/observer.html` — панель наблюдателя: 2 клика на событие (squad → тип события/приказ).
- `Server/wwwroot/dashboard.html` — read-only живая лента для Main Commander.

Никаких дополнительных NuGet-пакетов не требуется — серверная часть SignalR входит
в shared framework ASP.NET Core, начиная с .NET Core 3.0.

## Запуск локально

```bash
cd Server
dotnet run
```

По умолчанию приложение поднимется на `https://localhost:5001` (или похожий порт — смотрите
вывод в консоли). Откройте в браузере:

- `https://localhost:5001/observer.html` — для наблюдателя
- `https://localhost:5001/dashboard.html` — для командования

Откройте `observer.html` в нескольких вкладках/окнах — это симулирует несколько наблюдателей.

## Тест с телефона / другого ПК (то, что нужно для реального теста на GvG)

Локальный сервер недоступен снаружи вашей сети напрямую. Проще всего пробросить порт через
туннель на время теста, например:

```bash
# любой из вариантов, выберите то, что уже установлено
ngrok http https://localhost:5001
# или
cloudflared tunnel --url https://localhost:5001
```

Полученную публичную ссылку раздайте участникам теста (наблюдателям + 2-3 игрокам, которые
обычно молчат в войсе) вместе с `/observer.html` и `/dashboard.html`.

## Известные упрощения этого POC (осознанно, не баги)

- `Clients.All` вместо групп по squad/side — каждый видит вообще всё. В Phase 1 заменяется
  на routing по группам (архитектурный документ, раздел 8).
- История событий живёт только в памяти процесса — перезапуск сервера её стирает.
- Severity вычисляется по одному захардкоженному правилу (`TwinBlades` → Critical) —
  заглушка вместо `EventRoutingService` (раздел 13 документа).
- CORS разрешён отовсюду — приемлемо для одноразового теста в закрытом кругу гильдии,
  недопустимо для чего-либо постоянного.
